# 🚗 Driving Licenses Management System

The **Driving Licenses Management System** is a desktop application built with **C# (Windows Forms)** to manage driving licenses operations such as:
- Adding and managing people records.
- Issuing new licenses.
- Handling license tests (theoretical and practical).
- Tracking suspended or revoked licenses.

---

## ✅ Features
- Full management of people and licenses data.
- Ability to schedule and manage license tests before issuing.
- Support for license suspension and release.
- Simple and user-friendly interface using **WinForms**.
- SQL Server database integration for data storage.
- Implemented using **3-Tier Architecture**:
  - **Data Layer** – Handles database operations using raw SQL queries.
  - **Business Layer** – Core application logic.
  - **Presentation Layer** – User Interface (WinForms).

---

## 🛠 Tech Stack
- **C# (.NET Framework)**
- **Windows Forms**
- **SQL Server**
- **ADO.NET**
- **3-Tier Architecture**

---

## 🚀 Installation & Run
1. Clone the repository:
    ```bash
    git clone git@github.com:ahmedragab13579/A-Project-For-Driving-licenses-.git
    ```
2. Open the solution in **Visual Studio**.
3. Configure the **SQL Server Connection String** in the settings file.
4. Create the database and run the provided SQL scripts (if available).
5. Build and run the project.
